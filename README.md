# 📸 Photography Portal — A Digital Guide to the History of Photography

**Live Demo:** [https://pushkinaalexandra.github.io/photography-portal/](https://pushkinaalexandra.github.io/photography-portal/)

An interactive educational portal covering the history, techniques, genres, and key figures of photography. This project was developed as a portfolio piece to demonstrate front-end development skills and an understanding of art historical content.

## ✨ Features

- **Persons** — biographies of 21 influential photographers with photo sliders.
- **Gallery** — Masonry grid gallery with a filter by author.
- **Technique** — overview of 11 photographic techniques with side navigation.
- **Genres** — 4 major genres (Portrait, Landscape, Street, Documentary) with internal cross-links.

## 🛠️ Technologies Used

- **HTML5 & CSS3** — responsive layout and styling.
- **JavaScript (jQuery)** — sliders, filtering, smooth scrolling.
- **Masonry.js** — grid layout for the gallery.
- **GitHub Pages** — hosting.

## 📂 Project Structure
photography-portal/

├── Genre.html # Overview of photographic genres

├── *.js # Logic for each page

## 🚀 How to Run Locally

1. Clone the repository
2. Open `index.html` in your browser
